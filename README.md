# 一起来做螺壳

螺壳（luoke）是一组只在你自己的 Mac 上跑的 AI 应用：模型、记忆、你交给它们的东西，都留在这台电脑里。

这个仓库是大家参与螺壳的地方：许愿、投稿、聊想法，都在这里。

[English](#english)

## 许个愿

不会写代码也没关系。你想让本地 AI 帮你做什么，到 [Discussions → Ideas](https://github.com/luokelabs/luoke-contribute/discussions/categories/ideas) 开一个帖子：

- 一个帖子只说一件事，用大白话写清楚：在什么时候、想让它帮你做什么。
- 看到喜欢的愿望，点 ⬆️ 投一票（没有 GitHub 账号的话，在官网许愿墙上点 ❤️ 也算）。票多的，我们先做。
- 网站上的许愿墙会挑一部分放上去：[luoke.ai/contribute](https://luoke.ai/contribute)。

## 投稿

做了一个只在本机跑的 AI 小工具、一个输入法引擎，或者跑了一份你机器上的实测，都欢迎。

1. **开一个帖子**：在 [Issues](https://github.com/luokelabs/luoke-contribute/issues/new) 里说说它做什么、怎么跑、用户的数据会去哪。
2. **我们一起看一遍**：照下面几条对一对，有问题在帖子里聊。
3. **合适，就搬进来**：一起把它放进螺壳，署上你的名字。

写输入法引擎可以先看 [怎么写一个引擎](https://luoke.ai/ime/engines)。

### 我们一直守着的几件事

- 东西只在本机跑，不把用户的东西传出去，哪怕只是一点统计。
- 模型全机只有一份，要用就经螺壳，不自己再装一份。
- 改东西、发东西、删东西之前，都要先问用户。
- 密码、验证码这类秘密不碰。

### 也欢迎这些

- **你机器上的实测**：写清芯片和内存，补上我们手上没有的机型。
- **问题和想法**：哪里不好用、缺了什么；卡住了附上日志。不用贴你的邮件和打的字。
- **写写你怎么用**：你拿螺壳做了什么，在哪台机器上跑得怎么样。

## 说话的规矩

友好、就事论事。广告、人身攻击、泄露别人隐私的内容会被删掉。

## English

Luoke is a set of AI apps that run only on your own Mac. This repo is where you take part:

- **Make a wish** — post in [Discussions → Ideas](https://github.com/luokelabs/luoke-contribute/discussions/categories/ideas) what you'd like local AI to do for you, and upvote the ones you like. The most-voted get built first.
- **Contribute** — open an [issue](https://github.com/luokelabs/luoke-contribute/issues/new) describing what your tool does, how it runs and where user data goes. We review it together against the rules above (local only, one shared model through Luoke, ask before acting, no secrets), and if it fits, we bring it in with your name on it.
